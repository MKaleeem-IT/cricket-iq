ℹ️ About Cricket IQ

Project information, methodology, and technologies used.

🏏 Cricket Match Analysis & Outcome Prediction

This project analyzes historical ICC Men's T20 World Cup data and applies Machine Learning to predict possible match winners.

Users can enter match details (teams, venue, toss) and the trained Logistic Regression model generates a prediction.

The upcoming match module uses recent team performance and historical data to estimate outcomes of future Men's and Women's T20 fixtures.
